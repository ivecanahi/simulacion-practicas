4.  Marco Conceptual

Un modelo de simulación representa el comportamiento de un sistema mediante variables, parámetros, ecuaciones y reglas. En esta práctica el sistema de estudio es el crecimiento poblacional, que se modela de cuatro formas.

Modelo determinístico. No usa aleatoriedad: con los mismos parámetros siempre produce el mismo resultado. Se usa el crecimiento exponencial, donde P0 es la población inicial, r la tasa de crecimiento y t el tiempo:

P(t) = P0·ert

Modelo discreto. La población cambia solo en intervalos de tiempo definidos (períodos enteros):

Pt+1 = Pt + r·Pt

Modelo estocástico. Incorpora una variable aleatoria con distribución normal de media 0, donde σ representa el nivel de variabilidad del sistema. Cada ejecución produce un resultado distinto:

Pt+1 = Pt + r·Pt + εt,    εt ~ N(0, σ²)

Modelo continuo. Supone que la población cambia en todo instante, según la ecuación diferencial dP/dt = rP. Se resuelve numéricamente con el método de Euler, donde Δt es el tamaño del paso:

Pt+Δt = Pt + Δt·(r·Pt)

5.  Procedimiento / Metodología Ejecutada

  1. Se tomaron los datos de la guía: [1000, 1100, 1250, 1400, 1600, 1850, 2100], que representan la población observada en 7 períodos.
  2. A partir de los datos se estimaron los parámetros:
    • P0 = 1000 (primer dato).
    • r = 0.1318, promedio de la tasa de crecimiento por período (Pt+1 − Pt)/Pt.
    • σ = 24.50, desviación estándar del residuo entre los datos y la predicción del modelo discreto.
    • tiempo = 6 períodos y Δt = 0.1 para el modelo continuo.
  3. Se implementaron los cuatro modelos en Python siguiendo el pseudocódigo de la guía, con arquitectura Modelo-Vista-Controlador. En el estocástico, si la población queda negativa se fija en 0. Se usó una semilla fija (42) para que las corridas sean reproducibles.
  4. Se escribieron pruebas unitarias que verifican cada fórmula: por ejemplo, el estocástico con σ = 0 es igual al discreto, y Euler con Δt = 1 también es igual al discreto.
  5. Se ejecutaron los cuatro modelos y se compararon con los datos mediante el error medio absoluto (MAE) y la raíz del error cuadrático medio (RMSE).
  6. Se analizaron tres escenarios: distintas tasas r (positivas y negativas), distintos niveles de ruido σ (30 corridas cada uno) y distintos pasos Δt.

Interpretación. El modelo discreto es el que mejor se ajusta a los datos (MAE 23.07), porque los datos son observaciones por período y r se estimó como tasa por período; su solución cerrada es Pt = P0(1 + r)t. El determinístico y el continuo sobreestiman la población (≈ 2200 frente a 2100 en t = 6): con la misma r, er = 1.1409 es mayor que 1 + r = 1.1318, porque el crecimiento continuo se acumula a cada instante. La tasa continua equivalente sería ln(1 + r) ≈ 0.1238.

Influencia de r. La tasa determina la dirección y la velocidad del cambio. Con r > 0 la población crece de forma exponencial (2102 con r = 0.1318; 2986 con r = 0.20). Con r = 0 se mantiene constante, y con r < 0 decrece hacia 0 (262 con r = −0.20). Como el crecimiento es exponencial, una diferencia pequeña en r se amplifica con el tiempo.

Efecto de la aleatoriedad. Con σ pequeño las corridas casi coinciden con el modelo discreto. Al aumentar σ, las trayectorias se separan cada vez más: la desviación estándar de la población final pasa de 28 a 84 y a 381. Con σ = 98 incluso aparecen corridas que decrecen temporalmente aunque r > 0. Sin embargo, el promedio de las corridas se mantiene cerca del discreto, porque el ruido tiene media 0.

Discreto frente a continuo. Con Δt = 1, el método de Euler es idéntico al modelo discreto (error final 103.2 frente a la solución exacta). Al reducir Δt el error disminuye: 54.3 con Δt = 0.5, 11.4 con Δt = 0.1 y 1.1 con Δt = 0.01. Es decir, Euler converge al modelo continuo exacto cuando Δt tiende a 0.

7.  Preguntas de Control

  1. ¿Qué representa el arreglo de entrada?

    La población observada del sistema real en 7 períodos consecutivos. De él se obtienen los parámetros P0, r y σ, y sirve como referencia para medir el error de cada modelo.

  2. ¿Cuál es la diferencia entre un modelo determinístico y uno estocástico?

    El determinístico siempre produce el mismo resultado con los mismos parámetros. El estocástico incluye una variable aleatoria (ε), por lo que cada ejecución da un resultado distinto y debe analizarse con varias corridas (promedio y dispersión).

  3. ¿Qué efecto produce modificar la tasa (r)?

    Controla la dirección y la velocidad del cambio: una r mayor produce un crecimiento más rápido, r = 0 mantiene la población constante y r < 0 produce decrecimiento. Por ser un modelo exponencial, una diferencia pequeña en r se amplifica con el tiempo.

  4. ¿Qué representa el parámetro σ?

    Es la desviación estándar del ruido ε: el nivel de variabilidad o incertidumbre del sistema, causado por factores que el modelo no considera (clima, enfermedades, migración).

  5. ¿Qué ocurre cuando aumenta el nivel de ruido?

    Las trayectorias se separan más entre sí y del modelo sin ruido, y aumenta la incertidumbre del resultado final (de 28 a 381 de desviación al pasar de σ = 12.3 a σ = 98). La tendencia promedio no cambia, porque el ruido tiene media 0.

  6. ¿Cuál es la diferencia entre los modelos discreto y continuo?

    El discreto actualiza la población a saltos, una vez por período. El continuo supone que cambia en todo instante (dP/dt = rP), por lo que, con la misma r, crece un poco más. En el computador el continuo se aproxima con pasos pequeños mediante el método de Euler.

  7. ¿Qué función cumple (dt)?

    Es el tamaño del paso de la aproximación de Euler. Un Δt más pequeño da un resultado más preciso, más cercano a P0·ert, a cambio de más cálculos. Con Δt = 1 el modelo continuo se convierte en el discreto.

  8. ¿Por qué es importante visualizar los resultados mediante gráficas?

    Porque permiten ver de un vistazo tendencias, diferencias entre modelos, la dispersión producida por el ruido y el ajuste a los datos, aspectos difíciles de detectar en una tabla de números.

  9. ¿Qué modelo presenta comportamiento aleatorio?

    Solo el modelo estocástico, por el término εt ~ N(0, σ²).

  10. ¿Cómo cambia la simulación cuando se introduce un nuevo arreglo de datos?

    Cambian los parámetros estimados (P0, r y σ) y, por lo tanto, todas las curvas. Por ejemplo, con [2100, 1900, 1750, 1600, 1400, 1300, 1150] se obtiene r = −0.0953 y σ = 32.54, y los cuatro modelos muestran decrecimiento. El programa acepta cualquier arreglo por línea de comandos.

8.  Conclusiones

  • Los cuatro paradigmas describen el mismo fenómeno, pero sus supuestos (tiempo discreto o continuo, con o sin aleatoriedad) producen resultados distintos.
  • Para datos observados por período, el modelo discreto es el más adecuado (MAE 23.07). El continuo requiere usar la tasa continua equivalente ln(1 + r) para ser comparable.
  • El método de Euler aproxima el modelo continuo con un error que disminuye al reducir Δt. Con Δt = 1 coincide con el modelo discreto.
  • La aleatoriedad no cambia la tendencia del sistema, sino su incertidumbre. Por eso un modelo estocástico debe evaluarse con muchas corridas y no con una sola.

9.  Recomendaciones

  • Fijar una semilla aleatoria al simular modelos estocásticos, para que los resultados sean reproducibles y verificables.
  • Estimar r de forma coherente con el tipo de modelo: tasa por período para el discreto y ln(1 + r) para el continuo.
  • Considerar un modelo logístico, con capacidad de carga, para simulaciones a largo plazo, ya que el exponencial crece sin límite.
  • Integrar la visualización en NetLogo mediante pyNetLogo, mencionada en la guía, para observar el comportamiento del sistema de forma interactiva.

def stochastic_model(p0, r, sigma, time, rng=None):
    rng = rng if rng is not None else np.random.default_rng()
    population = [p0]
    for _ in range(time):
        noise = rng.normal(0, sigma)
        current = population[-1]
        new_population = current + r * current + noise
        population.append(max(new_population, 0.0))
    return np.arange(time + 1), np.array(population, dtype=float)

def continuous_model(p0, r, time, dt):
    steps = int(round(time / dt))
    t = np.linspace(0, steps * dt, steps + 1)
    population = [p0]
    for _ in range(steps):
        current = population[-1]
        population.append(current + dt * (r * current))
    return t, np.array(population, dtype=float)
